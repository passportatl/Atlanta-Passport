# Passport ATL – Sprint 3: Premium API Integrations & Intelligent Event Aggregation

Implement Sprint 3 of Passport ATL's automatic event ingestion system.

## Objective

Expand Passport ATL into a comprehensive Atlanta event aggregation platform by integrating major event APIs in addition to the Ticketmaster, iCal, RSS, JSON, and XML sources completed in previous sprints.

Sprint 3 should **extend the existing architecture** without replacing any working functionality.

The following integrations must remain fully operational:

* Manual events
* Google Sheets imports
* Ticketmaster
* iCal feeds
* RSS feeds
* JSON feeds
* XML feeds
* Pending Review workflow
* Deduplication engine

No existing integrations should be removed or broken.

---

# Priority API Integrations

Integrate as many of the following APIs as possible, beginning with those that provide public APIs or support developer accounts.

## Tier 1 (Highest Priority)

* Eventbrite
* Meetup
* Bandsintown
* SeatGeek

## Tier 2

If API access is available:

* PredictHQ
* Fever
* Eventeny
* Humanitix
* Universe
* TicketLeap
* SimpleTix
* Eventbee

If an API requires paid credentials that are unavailable, build the connector framework but leave the source disabled with a clear configuration requirement.

---

# Connector Architecture

Each provider should be implemented as an independent connector.

Every connector should support:

* enable / disable
* manual sync
* scheduled sync
* health status
* sync history
* error logging
* API authentication
* rate limit handling
* retry handling

The system should allow future connectors to be added with minimal code changes.

---

# Authentication

Use environment variables for all API credentials.

Do not hardcode:

* API keys
* OAuth tokens
* secrets
* client IDs

If credentials are unavailable:

* do not fail the application
* disable only that connector
* report the missing configuration

---

# Intelligent Deduplication

Extend the current deduplication engine.

Prevent duplicates across:

* Ticketmaster
* Eventbrite
* Meetup
* Bandsintown
* SeatGeek
* RSS
* XML
* JSON
* iCal
* Google Sheets
* Manual events

Use weighted matching based on:

* external ID
* normalized title
* venue
* address
* coordinates
* event URL
* ticket URL
* start date
* start time

When duplicate confidence is high:

* merge source references
* preserve richer metadata
* retain editorial content
* update only source-controlled fields

Never overwrite manual edits.

Eventbrite
