# Intelligent Retry System

Implement automatic retry handling.

Suggested behavior:

Authentication failure

* stop retries
* mark Awaiting Credentials

HTTP 429

* exponential backoff

Temporary network failures

* retry automatically

5xx server errors

* exponential retry

Malformed feeds

* disable source after repeated failures

Each connector should maintain independent retry state.

One failing source must never stop another source from syncing.

# Advanced Deduplication

Strengthen duplicate detection.

Current duplicate matching should expand to include weighted confidence scoring.

Signals include:

* External ID
* Title similarity
* Start date
* Start time
* Venue
* Address
* Coordinates
* Event URL
* Ticket URL
* Organizer
* Category

Support fuzzy matching.

Generate a duplicate confidence score.

Examples:

100%

* same external ID

95%

* same title
* same venue
* same time

80%

* similar title
* nearby venue
* same day

Automatically:

* merge safe duplicates
* flag uncertain duplicates for review

Never overwrite editorial content.
