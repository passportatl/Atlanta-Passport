LOGO / WORDMARK DIRECTION

Create a custom “Atlanta Passport” wordmark component.

It should be inspired by classic roadside block signage, but NOT a direct Waffle House copy.

Logo treatment:
Each word or letter group sits in warm yellow rounded rectangle blocks.
Use bold black uppercase letters.
Slightly imperfect, playful alignment.
Optional subtle shadow.
Feels like a sign, sticker, badge, or patch.

Example structure:
[ ATLANTA ]
[ PASSPORT ]

or:
[ ATL ][ ANT ][ A ]
[ PASS ][ PORT ]

Use CSS only if possible.

Code suggestion:
Create a LogoBlock component:
- wrapper: display inline-grid
- each word in a yellow block
- black uppercase text
- border: 3px solid black
- border-radius: 8px
- box-shadow: 4px 4px 0 black
- transform rotations: slight -1deg / 1deg
- font-weight: 900
- letter-spacing: .04em

Example CSS:

.logo-block {
  display: inline-grid;
  gap: 6px;
  transform: rotate(-1deg);
}

.logo-row {
  display: flex;
  gap: 6px;
  justify-content: center;
}

.logo-tile {
  background: var(--passport-yellow);
  color: var(--passport-black);
  border: 3px solid var(--passport-black);
  border-radius: 8px;
  box-shadow: 4px 4px 0 var(--passport-black);

}

  transform: rotate(1deg);
}

  transform: rotate(-1deg);
}
