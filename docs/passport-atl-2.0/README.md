# Passport ATL 2.0 Documentation

This directory is the planning and delivery record for Passport ATL 2.0. It
separates product intent, experience standards, engineering plans, decisions,
and release evidence so each can evolve without obscuring the others.

## Structure

| Section | Contents |
| --- | --- |
| [Product](product/README.md) | Vision, outcomes, scope, and success measures |
| [Design](design/README.md) | Experience principles, flows, and UI guidance |
| [Engineering](engineering/README.md) | Technical plans, contracts, testing, and operations |
| [Decisions](decisions/README.md) | Architecture and product decision records |
| [Releases](releases/README.md) | Release plans, readiness evidence, and retrospectives |

## Working agreements

- Link plans to an issue, milestone, or decision record when one exists.
- Mark assumptions and unresolved questions explicitly.
- Record durable decisions; do not rely on chat history.
- Keep planned behavior distinct from current behavior.
- Update the relevant document in the same pull request as an accepted change.
- Avoid personal data, credentials, and sensitive operational details.

The repository-wide contribution workflow is in
[CONTRIBUTING.md](../../CONTRIBUTING.md), the system overview is in
[ARCHITECTURE.md](../../ARCHITECTURE.md), and sequencing is summarized in
[ROADMAP.md](../../ROADMAP.md).
