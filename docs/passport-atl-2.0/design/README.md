# Design

Design documents define the intended Passport ATL 2.0 experience across mobile
and desktop.

Capture:

- information architecture and user flows;
- responsive behavior and interaction states;
- component and content guidance;
- accessibility requirements, including keyboard and screen-reader behavior;
- research findings, prototypes, and validation evidence.

Every feature specification should cover loading, empty, error, offline or
degraded, and success states where applicable. Link source designs rather than
checking large generated exports into this directory.
