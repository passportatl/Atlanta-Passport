# Product

Product documents explain why Passport ATL 2.0 work matters and how success
will be evaluated.

Include:

- problem statements and target audiences;
- desired outcomes and measurable indicators;
- in-scope and out-of-scope behavior;
- journey maps and acceptance criteria;
- assumptions, risks, dependencies, and open questions.

Start each proposal with its status, owner, last-updated date, and links to
related issues or decision records. Avoid prescribing implementation unless it
is a genuine product constraint.
