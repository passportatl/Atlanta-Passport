# Releases

Release documents collect the evidence needed to ship and learn from Passport
ATL 2.0 changes.

For each release or milestone, record:

- scope and linked changes;
- owners and target environments;
- migration, rollout, and rollback steps;
- automated and manual verification results;
- accessibility, performance, security, and privacy checks;
- monitoring signals and incident contacts;
- known issues and follow-up work;
- post-release outcomes or retrospective notes.

Use dated filenames such as `2026-09-explore-beta.md`. Never include secrets,
tokens, production user data, or private contact details.
